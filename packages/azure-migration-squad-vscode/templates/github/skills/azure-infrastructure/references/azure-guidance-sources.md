# Azure Guidance Sources

This reference points to authoritative, maintained sources. The links were checked on 2026-11-26; that date does not validate any example or API version below.

Before recommending an Azure service, SKU, quota, API version, provider version, or deployment setting:

1. Consult the current product documentation below and the relevant service-specific Learn documentation.
2. Verify regional availability, limits, and support for the selected workload.
3. Treat repository snippets as illustrative. Do not copy a version number without checking its current support and compatibility.
4. State when current documentation could not be retrieved; do not imply that an unverified example is current.
